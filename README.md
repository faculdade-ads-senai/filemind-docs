## Repositórios do projeto

- `filemind-backend`: API Java/Spring Boot (usuários, login, arquivos e armazenamento);
- `filemind-frontend`: aplicação web em React;
- `filemind-rag`: serviço Python de indexação e perguntas com fontes, preparado para AWS Lambda;
- `filemind-docs`: documentação transversal do projeto (este repositório).

O código ativo deve permanecer nos repositórios de implementação. Este repositório registra decisões, modelos e orientações compartilhadas pelo grupo.
